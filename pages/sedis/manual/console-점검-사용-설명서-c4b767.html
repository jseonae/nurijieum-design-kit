02

내 계정 · 비밀번호 바꾸기

콘솔 오른쪽 위 「마이페이지」에서 자기 비밀번호를 바꾼다.

매뉴얼에서 보기

이 사이트 이 서버는 모든 계정 비밀번호가 (개발 서버 비밀번호) 로 고정입니다. 비밀번호 바꾸기는 점검직원2(E2026902)로 해 보고, 끝나면 서브관리자관리 ⋮ 「비밀번호 초기화」로 (개발 서버 비밀번호) 로 되돌립니다. ksh · siteadmin · operator 같은 공용 계정은 바꾸지 않습니다.

  1. 여기서부터 시크릿창 — 일반창의 관리자 로그인은 그대로 둡니다
  2. 1 운영자 관리자 화면 시크릿창
    길 찾기 /console-9f3a/ › 마이페이지

    오른쪽 위 이름 → 「마이페이지」로 「내 계정」 화면을 엽니다.

    확인 계정 정보(아이디 · 이름 · 등급)와 「비밀번호 변경」 칸이 보인다.

    화면 보기
  3. 2 운영자 관리자 화면 시크릿창

    현재 비밀번호를 틀리게 넣고 새 비밀번호 두 칸을 채워 저장합니다.

    확인 「현재 비밀번호가 맞지 않습니다」 안내. 로그인 실패 횟수는 늘지 않는다.

  4. 3 운영자 관리자 화면 시크릿창

    맞게 넣어 저장한 뒤 로그아웃하고 새 비밀번호로 다시 로그인합니다.

    확인 바꿨다는 안내, 새 비밀번호로 로그인된다. 규칙(2종 10자 · 3종 8자)에 못 미치면 저장되지 않는다.

03

서브관리자 등록 → 직원 첫 로그인 → 계정 삭제

부서 및 조직의 직원을 서브관리자로 올리면 직원 로그인 계정이 생긴다. 직원은 맡은 메뉴만 본다.

매뉴얼에서 보기
준비
  • 부서 및 조직에 있는, 로그인 계정이 없는 직원 한 명
  • 그 직원에게 줄 관리자 권한그룹 하나(게시판 하나를 맡은 그룹)

이 사이트 직원은 점검부서A 의 점검직원1(E2026901), 권한그룹은 「점검-게시판담당」(게시판1 담당)을 고릅니다. 사이트는 「개발용 사이트」.

  1. 1 전체관리자 관리자 화면 일반창
    길 찾기 운영관리 › 권한 › 서브관리자관리 › 서브관리자 등록

    「찾아서 고르기」에 직원 이름을 쳐서 고르고, 권한그룹에 체크한 뒤 「서브관리자로 등록」을 누릅니다.

    확인 고른 사람 카드에 부서 · 직위가 보이고, 등록하면 서브관리자 목록에 그 사번 줄이 「새로 등록」 표시와 함께 생긴다.

    화면 보기
  2. 2 전체관리자 관리자 화면 일반창
    길 찾기 › 복사 › 확인

    뜬 창의 임시 비밀번호 옆 「복사」를 누르고, 다음 단계에 쓸 수 있게 따로 적어 둔 뒤 「확인」으로 닫습니다(점검 결과 메모에는 적지 않습니다 — 점검 현황에서 누구나 봅니다).

    확인 「로그인 계정을 만들었습니다」 창에 임시 비밀번호가 크게 보이고 「복사했습니다」가 뜬다. 배경을 누르거나 Esc 로는 닫히지 않는다.

    이 사이트 이 서버는 고정 비밀번호라 창에 (개발 서버 비밀번호) 가 뜹니다. 복사 · 메모는 건너뛰어도 됩니다.

  3. 여기서부터 시크릿창 — 일반창의 관리자 로그인은 그대로 둡니다
  4. 3 서브관리자 로그인 화면 시크릿창
    길 찾기 /console-9f3a/login/staff

    사번과 임시 비밀번호로 「로그인」 한 뒤, 열린 화면에서 새 비밀번호를 정해 저장합니다.

    확인 로그인하자마자 「내 계정」 비밀번호 바꾸기 화면으로 가고, 저장하면 「비밀번호를 바꿨습니다. 이제 콘솔의 다른 화면을 쓸 수 있습니다.」

    이 사이트 이 서버는 첫 로그인 변경 강제가 꺼져 있습니다 — 사번 · (개발 서버 비밀번호) 로 바로 들어가고 비밀번호 바꾸기 화면으로 가지 않으면 통과입니다.

    화면 보기
  5. 4 서브관리자 관리자 화면 시크릿창
    길 찾기 사이트 관리 › 게시판 관리

    왼쪽 메뉴를 훑고 「게시판 관리」를 엽니다.

    확인 오른쪽 위 「서브관리자」. 메뉴는 대시보드 · 내 담당 메뉴 · 콘텐츠 관리 · 게시판 관리 정도이고, 게시판 목록에는 그룹이 맡은 게시판만 보인다.

    이 사이트 게시판 관리(개발용 사이트) 목록에 「게시판1」 하나만 보이면 통과입니다.

    화면 보기
