1장 로그인 · 내 계정

관리자 · 직원 로그인, 잠금과 풀기, 비밀번호 바꾸기

1.1 관리자 로그인 · 잠금 · 접속 제한 풀기

목적 로그인과 로그아웃, 비밀번호를 5번 틀리면 잠기고 전체관리자가 풀어 준다.

준비
  • 잠가 볼 관리자 계정 하나(운영자 등급이면 된다)

하는 법

  1. 1 전체관리자 로그인 화면

    길 찾기 /console-9f3a/login

    아이디 · 비밀번호를 넣고 「로그인」을 누릅니다.

    결과 대시보드가 열리고, 오른쪽 위에 이름과 「전체관리자」가 보인다.

  2. 2 전체관리자 관리자 화면

    길 찾기 /console-9f3a/ ›로그아웃

    오른쪽 위 이름을 눌러 「로그아웃」 한 뒤 다시 로그인해 둡니다.

    결과 로그인 화면으로 돌아오고, 다시 로그인하면 보던 콘솔로 들어간다.

  3. 3 운영자 로그인 화면

    길 찾기 /console-9f3a/login

    계정 아이디에 틀린 비밀번호를 5번 넣습니다.

    결과 4번째까지는 「아이디 또는 비밀번호」 안내, 5번째부터 「로그인에 여러 번 실패해 잠겼습니다」. 맞는 비밀번호도 들어가지 않는다.

  4. 4 전체관리자 관리자 화면

    길 찾기 운영관리›권한 ›서브관리자관리 탭 ›⋮ 접속 제한 풀기

    잠근 계정 줄의 「로그인 실패」 칸을 보고, 줄 끝 ⋮ → 「접속 제한 풀기」를 누릅니다.

    결과 그 줄 상태가 「접속 제한」에서 「정상」으로, 실패 횟수가 0회로 바뀐다.

  5. 5 운영자 로그인 화면

    길 찾기 /console-9f3a/login

    맞는 비밀번호로 다시 로그인합니다.

    결과 들어가진다. 왼쪽 메뉴에 「운영관리」 묶음이 없다(운영자).

1.2 내 계정 · 비밀번호 바꾸기

목적 콘솔 오른쪽 위 「마이페이지」에서 자기 비밀번호를 바꾼다.

하는 법

  1. 1 운영자 관리자 화면

    길 찾기 /console-9f3a/ ›마이페이지

    오른쪽 위 이름 → 「마이페이지」로 「내 계정」 화면을 엽니다.

    결과 계정 정보(아이디 · 이름 · 등급)와 「비밀번호 변경」 칸이 보인다.

  2. 2 운영자 관리자 화면

    현재 비밀번호를 틀리게 넣고 새 비밀번호 두 칸을 채워 저장합니다.

    결과 「현재 비밀번호가 맞지 않습니다」 안내. 로그인 실패 횟수는 늘지 않는다.

  3. 3 운영자 관리자 화면

    맞게 넣어 저장한 뒤 로그아웃하고 새 비밀번호로 다시 로그인합니다.

    결과 바꿨다는 안내, 새 비밀번호로 로그인된다. 규칙(2종 10자 · 3종 8자)에 못 미치면 저장되지 않는다.

2장 권한

서브관리자(직원) 계정, 권한그룹과 명단, 관리자 접속 IP — 전체관리자만

2.1 서브관리자 등록 → 직원 첫 로그인 → 계정 삭제

목적 부서 및 조직의 직원을 서브관리자로 올리면 직원 로그인 계정이 생긴다. 직원은 맡은 메뉴만 본다.

준비
  • 부서 및 조직에 있는, 로그인 계정이 없는 직원 한 명
  • 그 직원에게 줄 관리자 권한그룹 하나(게시판 하나를 맡은 그룹)

하는 법

  1. 1 전체관리자 관리자 화면

    길 찾기 운영관리›권한 ›서브관리자관리 탭 ›서브관리자 등록

    「찾아서 고르기」에 직원 이름을 쳐서 고르고, 권한그룹에 체크한 뒤 「서브관리자로 등록」을 누릅니다.

    결과 고른 사람 카드에 부서 · 직위가 보이고, 등록하면 서브관리자 목록에 그 사번 줄이 「새로 등록」 표시와 함께 생긴다.

  2. 2 전체관리자 관리자 화면

    길 찾기 ›복사›확인

    뜬 창의 임시 비밀번호 옆 「복사」를 누르고, 다음 단계에 쓸 수 있게 따로 적어 둔 뒤 「확인」으로 닫습니다.

    결과 「로그인 계정을 만들었습니다」 창에 임시 비밀번호가 크게 보이고 「복사했습니다」가 뜬다. 배경을 누르거나 Esc 로는 닫히지 않는다.

  3. 3 서브관리자 로그인 화면

    길 찾기 /console-9f3a/login/staff

    사번과 임시 비밀번호로 「로그인」 한 뒤, 열린 화면에서 새 비밀번호를 정해 저장합니다.

    결과 로그인하자마자 「내 계정」 비밀번호 바꾸기 화면으로 가고, 저장하면 「비밀번호를 바꿨습니다. 이제 콘솔의 다른 화면을 쓸 수 있습니다.」

  4. 4 서브관리자 관리자 화면

    길 찾기 사이트 관리›게시판 관리

    왼쪽 메뉴를 훑고 「게시판 관리」를 엽니다.

    결과 오른쪽 위 「서브관리자」. 메뉴는 대시보드 · 내 담당 메뉴 · 콘텐츠 관리 · 게시판 관리 정도이고, 게시판 목록에는 그룹이 맡은 게시판만 보인다.

  5. 5 서브관리자 관리자 화면

    길 찾기 /console-9f3a/identity

    주소창에 권한 화면 주소를 직접 넣어 엽니다.

    결과 「접근 권한이 없는 화면입니다」 화면이 뜬다.

  6. 6 전체관리자 관리자 화면

    길 찾기 ›서브관리자관리 탭 ›⋮ 비밀번호 초기화

    그 직원 줄 ⋮ → 「비밀번호 초기화」(사유 입력)를 누릅니다.

    결과 같은 「임시 비밀번호」 창이 다시 뜬다(복사 · 확인). 직원이 새 임시 비밀번호로 들어가면 다시 비밀번호 바꾸기 화면이다.

  7. 7 전체관리자 관리자 화면

    길 찾기 ›서브관리자관리 탭 ›변경›⋮ 계정 삭제

    그 직원의 권한그룹 「변경」에서 체크를 모두 빼고 저장한 뒤, ⋮ → 「계정 삭제」(사유 입력)를 누릅니다.

    결과 권한그룹이 남아 있는 동안에는 ⋮ 에 「계정 삭제」가 없다. 삭제하면 목록에서 그 줄이 사라진다.

  8. 8 서브관리자 로그인 화면

    길 찾기 /console-9f3a/login/staff

    지운 직원의 사번 · 비밀번호로 로그인해 봅니다.

    결과 「사번 또는 비밀번호가 맞지 않습니다」. 같은 사번을 다시 등록하면 새 계정으로 살아난다.

2.2 권한그룹 → 명단 → 메뉴 관리자 권한 → 그룹 삭제

목적 관리자 권한그룹에 직원 · 부서를 넣고 메뉴의 관리자 권한으로 주면 그 사람들이 그 메뉴를 맡는다.

준비
  • 서브관리자 계정이 있는 직원 한 명(앞 흐름에서 지우기 전에 해도 된다)
  • 맡겨 볼 메뉴 하나(게시판이나 콘텐츠가 연결된 메뉴)

하는 법

  1. 1 전체관리자 관리자 화면

    길 찾기 운영관리›권한 ›권한그룹관리 탭 ›권한그룹 등록

    그룹명 「예시-그룹」, 종류 「관리자」로 「등록하고 명단 추가」를 누릅니다.

    결과 오른쪽 권한그룹 창에 그 그룹의 명단 탭이 바로 열린다.

  2. 2 전체관리자 관리자 화면

    길 찾기 ›추가

    명단에 직원 한 명과 부서 하나를 넣습니다.

    결과 명단에 사람 줄과 부서 줄(부서원 수)이 생기고, 권한그룹관리 표의 인원 수가 늘어난다.

  3. 3 전체관리자 관리자 화면

    길 찾기 사이트 관리›메뉴관리 ›접근권한 탭 ›⋮ 수정하기

    맡길 메뉴의 「접근권한」 탭에서 관리자 권한에 「예시-그룹」을 고르고 「접근권한 저장」을 누릅니다(사유 입력).

    결과 관리자 권한 목록에 예시-그룹 줄이 생기고, 적용 요약의 관리자 권한 수가 하나 는다.

  4. 4 서브관리자 관리자 화면

    길 찾기 사이트 관리›내 담당 메뉴

    명단의 직원으로 로그인해 「내 담당 메뉴」를 엽니다(이미 로그인해 있었다면 로그아웃 후 다시).

    결과 맡긴 메뉴가 목록에 보이고, ⋮ 로 그 메뉴의 게시글 관리 또는 소스 수정을 열 수 있다.

  5. 5 전체관리자 관리자 화면

    길 찾기 운영관리›권한 ›권한그룹관리 탭 ›⋮ 수정하기

    「예시-그룹」 줄 ⋮ → 「수정하기」로 이름을 「예시-그룹2」로 저장합니다.

    결과 종류(관리자 · 회원)는 잠겨 있고, 목록 「최근 변경」에 오늘 날짜.

  6. 6 전체관리자 관리자 화면

    길 찾기 운영관리›권한 ›권한그룹관리 탭 ›⋮ 삭제하기›삭제

    ⋮ → 「삭제하기」 → 「삭제」.

2.3 권한그룹 명단 엑셀 업로드

목적 서식에 사번 · 부서코드 · 기간을 적어 올리면 미리보기에서 오류 줄을 걸러 넣는다.

준비
  • 명단을 넣어 볼 관리자 권한그룹 하나

하는 법

  1. 1 전체관리자 관리자 화면

    길 찾기 운영관리›권한 ›권한그룹관리 탭

    그룹 줄의 그룹명(또는 ⋮ → 「그룹회원」)을 누릅니다.

    결과 오른쪽에 권한그룹 창이 열리고 「명단 업로드」 단추가 있다.

  2. 2 전체관리자 관리자 화면

    길 찾기 ›명단 업로드›서식 내려받기

    「명단 업로드」 → 「서식 내려받기」로 받은 엑셀에 맞는 사번 한 줄, 부서코드 한 줄, 없는 사번 한 줄을 적습니다.

    결과 서식 머리줄이 사번 · 부서코드 · 기간이다.

  3. 3 전체관리자 관리자 화면

    「파일 올리기」에 그 엑셀을 넣고 미리보기를 봅니다.

    결과 맞는 줄은 「넣을 수 있음」, 없는 사번은 「없는 사번입니다.」, 아래에 「넣을 수 있음 2건 · 오류 1건」.

  4. 4 전체관리자 관리자 화면

    「2건 넣기」를 누르고 명단을 봅니다. 확인했으면 넣은 줄을 지웁니다.

    결과 명단에 사람 · 부서 줄이 기간과 함께 생긴다(권한 부여일은 「권한그룹명단관리」 탭 표에 오늘 날짜).

    길 찾기 ›⋮ 삭제하기

    ⋮ → 「삭제하기」(사유 입력).

3.2 메뉴 접근권한 — 누구나 · 회원 · 직원 · 권한그룹

준비

하는 법

  2. 2 비회원 사용자 화면

    그 메뉴 주소를 엽니다.

    결과 로그인 화면으로 가거나 「로그인이 필요합니다」 안내. 통합검색 결과에도 그 메뉴 내용이 나오지 않는다.

  3. 3 회원 로그인 화면

    길 찾기 /public/login

    회원으로 로그인하고 같은 주소를 다시 엽니다.

    결과 내용이 보인다.

  4. 4 운영자 관리자 화면

    길 찾기 ›접근권한 탭

    「권한그룹 추가」로 그 회원이 없는 회원 권한그룹을 넣어 보기를 켜고, 일반회원 보기를 끈 뒤 저장, 회원 창을 새로고침합니다.

    길 찾기 ›접근권한 탭

    「누구나」로 되돌려 저장합니다.

    결과 시크릿창 비회원으로 다시 열린다.

    길 찾기 ›메뉴코드 일괄 부여

    메뉴코드가 없는 메뉴가 있으면 목록 위 안내의 「메뉴코드 일괄 부여」 미리보기만 보고 닫습니다.

    결과 바뀔 코드가 전 → 후로 보인다(부여하지 않는다). 코드 없는 메뉴가 없으면 단추도 없다.

  5. 5 운영자 관리자 화면

    길 찾기 ›선택 삭제

    두 줄에 체크하고 「선택 삭제」.

    결과 목록에서 사라진다.

    결과 보관하면 공개 목록에서 사라진다. 지우면 콘솔 목록 · 공개 메뉴에서 모두 사라진다.

3.7 게시판 유형 — 갤러리 · 동영상 · 자주 묻는 질문 · 묻고 답하기 이 사이트에서 쓰지 않음

SEDIS 게시판은 공지 · 자료실 · 동영상(홍보영상 · 종단연구) 유형을 씁니다(갤러리 · 자주 묻는 질문 · 묻고 답하기는 새로 만들지 않음).

목적 유형마다 공개 화면 모양이 다르다. 묻고 답하기는 답변이 붙는다.

하는 법

  1. 1 운영자 관리자 화면

    길 찾기 사이트 관리›게시판 관리 ›게시판 등록

    유형 「갤러리」 게시판에 대표 이미지가 있는 글 하나를 올리고 메뉴에 붙입니다.

    결과 공개 목록이 썸네일 바둑판으로 보인다.

  2. 2 운영자 관리자 화면

    유형 「동영상」 게시판 글에 유튜브 URL 을 넣습니다.

    결과 공개 상세에 동영상이 들어간다.

  3. 3 비회원 사용자 화면

    유형 「자주 묻는 질문」 게시판의 공개 화면을 엽니다.

    결과 질문을 누르면 답이 펼쳐진다.

  4. 4 운영자 관리자 화면

    길 찾기 ›⋮ 처리하기›답변 등록

    유형 「묻고 답하기」 게시판(공개 화면을 보려면 메뉴에 붙인다) 글 ⋮ → 「처리하기」로 민원 처리 화면을 열어 답변 제목 · 내용을 쓰고 「답변 등록」.

    결과 공개 상세 아래에 답변이 붙는다. 확인이 끝나면 게시판들을 지운다.

3.10 부서 및 조직 — 부서 · 직원 · 일괄 등록 · 조직 이동

목적 조직도에 부서를 만들고 직원을 넣고 옮긴다. 서브관리자 등록과 권한그룹 부서 명단이 이 직원 명부를 쓴다.

하는 법

  1. 1 운영자 관리자 화면

    길 찾기 사이트 관리›부서 및 조직 ›부서추가›등록

    부서를 두 개 만듭니다 — 「예시-부서」(코드 QA_DEPT) · 「예시-부서2」(코드 QA_DEPT2). 부서 코드는 사이트 안에서 겹치지 않아야 한다(지운 부서의 코드도 다시 쓸 수 없다 — 다시 할 때는 다른 코드로).

    결과 조직도에 두 부서가 생긴다.

  2. 2 운영자 관리자 화면

    길 찾기 ›직원 추가›등록

    예시-부서에 이름 「예시-직원」, 사번, 이메일, 직위로 직원을 추가합니다.

    결과 오른쪽 직원 목록에 생긴다.

  3. 3 운영자 관리자 화면

    길 찾기 ›일괄 등록

    「일괄 등록」 패널에서 「엑셀」 서식을 받아 두 줄(사번 · 성명 · 부서 이름 · 직위는 꼭)을 적어 올리고 「등록」(서버가 먼저 전부 검사하고 오류가 없을 때만 등록한다).

    결과 미리보기에 추가 2건, 등록 뒤 목록에 두 사람.

  4. 4 운영자 관리자 화면

    길 찾기 ›조직 이동

    직원 한 명에 체크하고 「조직 이동」 → 예시-부서2.

    결과 그 직원이 예시-부서2 로 옮겨진다. 그 사람이 서브관리자면 부서 명단으로 받던 권한도 바뀐다.

  5. 5 운영자 관리자 화면

    길 찾기 ›삭제›부서삭제

    직원들을 지우고 두 부서를 지웁니다.

    결과 직원이 남은 부서는 지우지 못한다는 안내, 비우면 지워진다.

3.11 내 담당 메뉴 — 서브관리자가 맡은 것만 고치기

목적 서브관리자는 맡은 메뉴의 콘텐츠 소스 · 게시글만 고친다. 다른 메뉴는 보이지 않는다.

준비
  • 콘텐츠 메뉴 하나와 게시판 메뉴 하나를 맡은 서브관리자(메뉴 담당자로 지정하거나 권한그룹으로)

하는 법

  1. 1 서브관리자 관리자 화면

    길 찾기 사이트 관리›내 담당 메뉴

    「내 담당 메뉴」를 엽니다.

    결과 맡은 메뉴만 보이고, 줄마다 ⋮ 에 소스 수정 · 게시글 관리 등이 있다.

  2. 2 서브관리자 관리자 화면

    길 찾기 ›⋮ 소스 수정›소스 저장

    콘텐츠 메뉴의 「소스 수정」에서 글자 하나를 고쳐 「소스 저장」.

    결과 저장되고 버전 이력에 새 버전. 메뉴 정보 · 접근권한 탭은 보이지 않거나 잠겨 있다.

  3. 3 서브관리자 관리자 화면

    길 찾기 ›⋮ 게시글 관리›새 게시글

    게시판 메뉴의 게시글 관리에서 글 하나를 쓰고 보관합니다.

    결과 쓰고 보관할 수 있다. 게시판 ⋮ 에는 미리보기 · 게시글 관리뿐이라 게시판 설정 · 권한은 고칠 수 없다.

  4. 4 서브관리자 관리자 화면

    길 찾기 /console-9f3a/navigation

    메뉴관리 주소를 직접 엽니다.

    결과 「접근 권한이 없는 화면입니다」.

5장 운영관리

사이트 · 공통코드 · 관리자메뉴관리 · 접속기록 · 프로그램관리 · 운영 진단

5.1 사이트 등록 → 도메인 → 중지 · 삭제 이 사이트에서 쓰지 않음

SEDIS 는 사이트 하나로 운영합니다 — 새 사이트 · 도메인 등록이 설정으로 꺼져 있습니다(cms.admin-bff.sites.allow-create=false, sedis-app/docs/edition.md).

목적 새 사이트를 단계별로 만들고, 도메인을 붙이고, 지운다.

하는 법

  1. 1 전체관리자 관리자 화면

    길 찾기 운영관리›사이트 관리 ›새 사이트 등록

    사이트명 「예시-사이트」, 사이트 코드 「QA_SITE」로 등록합니다(도메인 · 홈 라우트 · 메뉴 구성 단계는 건너뛰기 가능). 새 사이트 등록은 전체관리자만 할 수 있다. 지운 사이트의 코드 · 도메인은 다시 쓸 수 없으니 다시 할 때는 다른 코드 · 도메인으로.

    결과 사이트 목록에 생기고, 위쪽 사이트 전환 목록에도 보인다.

  2. 2 전체관리자 관리자 화면

    길 찾기 ›⋮ 도메인 관리

    도메인 「qa.example.com」을 등록합니다.

    결과 도메인 목록에 생긴다.

  3. 3 전체관리자 관리자 화면

    길 찾기 운영관리›사이트 관리 ›⋮ 삭제하기

    「사이트 수정」에서 상태를 「중지」로 저장한 뒤 ⋮ → 「삭제하기」.

    결과 삭제 확인에 함께 지워지는 것(메뉴 · 콘텐츠 등)이 보이고, 지우면 목록과 사이트 전환에서 사라진다.

5.2 공통코드 그룹 · 코드 → 비활성 → 삭제

목적 게시판 유형 같은 선택 목록을 코드로 관리한다.

하는 법

  1. 1 사이트관리자 관리자 화면

    길 찾기 운영관리›공통코드 ›새 코드 그룹›등록

    그룹 코드 「QA_GROUP」, 그룹명 「예시-코드」, 적용 범위 「전체 공통」으로 등록합니다.

    결과 코드 그룹 목록에 생긴다.

  2. 2 사이트관리자 관리자 화면

    길 찾기 ›⋮ 코드 관리›새 코드 등록

    코드 「A」 · 코드명 「예시-가」, 코드 「B」 · 「예시-나」를 넣고 하나를 수정합니다.

    결과 코드 목록에 정렬순서대로 보이고 수정이 반영된다.

  3. 3 사이트관리자 관리자 화면

    길 찾기 운영관리›공통코드 ›⋮ 그룹 삭제

    코드 하나를 ⋮ → 「비활성화」 한 뒤, 그룹 목록에서 ⋮ → 「그룹 삭제」.

    결과 비활성 코드는 상태가 바뀌고, 그룹을 지우면 목록에서 사라진다.

5.3 관리자메뉴관리 — 권한그룹별로 콘솔 메뉴 열기

목적 콘솔 왼쪽 메뉴마다 어느 관리자 권한그룹이 보고 고칠 수 있는지 정한다.

준비
  • 관리자 권한그룹이 있는 서브관리자 한 명

하는 법

  1. 1 사이트관리자 관리자 화면

    길 찾기 운영관리›관리자메뉴관리 ›팝업존

    목록에서 「팝업존」 줄을 엽니다.

    결과 메뉴 정보 · 접근권한 · 수정 이력 탭, 구분과 「보고 고칠 수 있는 권한그룹」이 보인다.

  2. 2 사이트관리자 관리자 화면

    길 찾기 ›접근권한 탭

    「누가 보고 고칠 수 있나 — 권한그룹별」에서 「권한그룹 추가」로 서브관리자의 그룹을 넣어 「보기」만 켜고, 사유를 적어 「저장」합니다.

    결과 저장 안내, 목록 「보고 고칠 수 있는 권한그룹」 칸에 「그 그룹(보기)」.

  3. 3 서브관리자 관리자 화면

    서브관리자로 다시 로그인해 왼쪽 메뉴를 봅니다.

    결과 「팝업존」이 보이고 목록이 열린다. 「고치기」가 없으면 등록 · 수정 · 삭제 단추가 없고, 목록 내려받기(엑셀 · CSV)는 된다.

  4. 4 사이트관리자 관리자 화면

    그 그룹 줄의 「줄 빼기」로 거두고(필요하면 「상위 메뉴와 같게」를 다시 켜고) 사유를 적어 「저장」합니다.

    결과 서브관리자 화면에서 다시 사라진다(다시 로그인 뒤).

5.4 접속기록 — 작업 이력 · 로그인 기록 · 개인정보 열람 로그

목적 누가 언제 무엇을 했는지 기간 · 검색으로 찾고 CSV 로 내려받는다.

하는 법

  1. 1 사이트관리자 관리자 화면

    길 찾기 운영관리›접속기록 ›작업 이력 탭

    기간 「최근 7일」 그대로 오늘 한 일을 봅니다. 검색 항목 「내용」에 「점검」으로 「조회」.

    결과 앞 흐름에서 만든 · 고친 · 지운 일이 수행자 · 접속지와 함께 보인다.

  2. 2 사이트관리자 관리자 화면

    길 찾기 ›로그인 기록 탭

    「로그인 기록」 탭을 엽니다.

    결과 관리자 · 직원 · 회원 로그인 성공 · 실패 · 잠금 줄.

  3. 3 사이트관리자 관리자 화면

    길 찾기 ›개인정보 열람 로그 탭

    「개인정보 열람 로그」 탭을 엽니다.

    결과 회원 정보 열람 · 내려받기 줄이 행마다 열람 · 내려받기로 표시된다.

  4. 4 사이트관리자 관리자 화면

    기간을 「직접 입력」으로 오늘만 「조회」한 뒤 CSV 를 내려받습니다(사유 입력).

    결과 그날 줄만 나오고 CSV 가 받아진다. 내려받기 자체도 기록에 남는다.

5.5 프로그램관리 — 연결 서비스 화면 붙이기 이 사이트에서 쓰지 않음

프로그램관리 메뉴를 숨겼습니다 — SEDIS 화면은 이미 메뉴에 붙어 있습니다.

목적 등록된 연결 서비스(별도 앱)의 관리자 메뉴 · 사용자 화면을 골라 콘솔과 누리집에 붙인다.

하는 법

  1. 1 사이트관리자 관리자 화면

    길 찾기 운영관리›프로그램관리

    서비스 목록과 상태를 봅니다. 「다시 점검」을 누릅니다.

    결과 서비스마다 연결 상태 · 설명서 · 붙인 화면 수가 보인다.

  2. 2 전체관리자 관리자 화면

    길 찾기 ›저장

    서비스 하나의 사용자 화면 하나를 메뉴 유형 「프로그램」(연결 서비스 화면 선택)으로 메뉴에 붙여 공개 화면에서 봅니다. 확인 뒤 떼어 냅니다.

    결과 공개 누리집 레이아웃 안에 서비스 화면이 들어간다(새 창 · iframe 아님).

5.6 운영 진단

목적 서비스 연결 상태를 보고.

하는 법

  1. 1 사이트관리자 관리자 화면

    길 찾기 /console-9f3a/diagnostics ›다시 점검

    운영 진단 화면을 엽니다(메뉴에는 없음).

    결과 서비스 연결 상태가 모두 「UP」.

6장 사용자 화면 · 콘솔 공통

6.1 통합검색 · 사이트맵 · 오류 화면 · 글자 크기 · 고대비

목적 공개 누리집 공통 기능.

하는 법

  1. 1 비회원 사용자 화면

    길 찾기 /public/search

    위쪽 검색에 메뉴나 게시글에 있는 낱말을 넣습니다.

    결과 메뉴 · 콘텐츠 · 게시글 구획으로 결과가 나오고, 회원 전용 내용은 나오지 않는다.

  2. 2 비회원 사용자 화면

    길 찾기 /public/sitemap

    사이트맵을 엽니다.

    결과 공개 메뉴가 트리로 보인다. 숨긴 메뉴는 없다.

  3. 3 비회원 사용자 화면

    길 찾기 /public/없는-주소

    없는 주소를 엽니다.

    결과 누리집 모양의 「페이지를 찾을 수 없습니다」 화면.

  4. 4 비회원 사용자 화면

    화면의 글자 크기 · 고대비 설정을 바꿔 봅니다.

    결과 글자가 커지고 대비가 높아진다. 다른 화면으로 가도 유지된다.

6.2 콘솔 대시보드 · 빠른 이동 · 사이트 전환 · 글자 · 화면 설정

목적 콘솔 첫 화면과 머리말 공통 도구.

하는 법

  1. 1 사이트관리자 관리자 화면

    길 찾기 /console-9f3a/

    대시보드를 엽니다.

    결과 사이트 운영 현황 · 콘텐츠 처리 대기 · 최근 콘텐츠 · 최근 시스템 활동 로그가 보인다.

  2. 2 사이트관리자 관리자 화면

    길 찾기 /console-9f3a/

    대시보드의 구글 애널리틱스(GA4) 이용 통계를 봅니다.

    결과 페이지뷰 상위 · 메뉴별 조회 순위 · 브라우저 상위가 보이고 「GA 바로가기 ↗」가 새 창으로 열린다.

  3. 3 운영자 관리자 화면

    아무 화면에서 「/」 키를 눌러 빠른 이동에 메뉴 이름을 칩니다.

    결과 메뉴가 나오고 엔터로 그 화면이 열린다.

  4. 4 운영자 관리자 화면

    길 찾기 ›글자·화면 설정

    위쪽 사이트 전환으로 다른 사이트를 고르고, 「글자·화면 설정」에서 글자 크게 · 고대비를 바꿉니다.

    결과 목록 화면이 고른 사이트 것으로 바뀌고, 글자 · 대비 설정이 다른 화면에서도 유지된다.
